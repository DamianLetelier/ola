POLÍTICA DE PRIVACIDAD
Aegis Code Phish Detector - Extensión de Chrome
====================================================================

COMPROMISO DE PRIVACIDAD:
Aegis Code Phish Detector NO recopila, almacena ni comparte tus datos 
personales. Tu privacidad es nuestra máxima prioridad.

====================================================================
1. INFORMACIÓN GENERAL
====================================================================

Desarrollador: Aegis Code
Correo de contacto: codeaegis1@gmail.com
Última actualización: Enero 2025

Aegis Code Phish Detector es una herramienta de seguridad que analiza
texto seleccionado en páginas web para detectar posibles intentos de
phishing utilizando procesamiento de lenguaje natural (NLP).

====================================================================
2. DATOS NO RECOPILADOS
====================================================================

La Extensión NO recopila, almacena ni transmite:

❌ Información personal identificable (nombre, dirección, teléfono)
❌ Credenciales de acceso (contraseñas, tokens)
❌ Información financiera
❌ Historial de navegación completo
❌ Cookies o identificadores de seguimiento
❌ Datos de geolocalización
❌ Información del dispositivo

====================================================================
3. PROCESAMIENTO LOCAL
====================================================================

✅ Todo el análisis se realiza LOCALMENTE en tu navegador
✅ No se envían datos a servidores externos durante el análisis
✅ Los resultados se muestran solo a ti
✅ No se almacenan datos de análisis en tu dispositivo

====================================================================
4. REPORTES VOLUNTARIOS
====================================================================

Si optas VOLUNTARIAMENTE por reportar contenido sospechoso:

📧 Se abre tu cliente de correo predeterminado
✉️ TÚ decides qué información incluir
🔒 La extensión NO envía reportes automáticamente
👤 Puedes incluir o excluir tu correo a tu discreción

====================================================================
5. PERMISOS DE LA EXTENSIÓN
====================================================================

contextMenus:
- Propósito: Agregar opción "Analizar si es phishing" en menú contextual
- Uso: Solo cuando tú lo solicitas

activeTab:
- Propósito: Acceder al texto seleccionado en la pestaña activa
- Uso: Solo cuando inicias un análisis

notifications:
- Propósito: Mostrar notificaciones con resultados del análisis
- Uso: Informarte sobre el nivel de riesgo detectado

scripting:
- Propósito: Insertar la interfaz de resultados en la página
- Uso: Mostrar resultados directamente en la página

host_permissions (<all_urls>):
- Propósito: Permitir el análisis en cualquier sitio web
- Uso: Solo cuando TÚ inicias un análisis explícitamente

IMPORTANTE: La extensión NO monitorea tu navegación. Solo accede al
texto cuando TÚ lo seleccionas y solicitas un análisis.

====================================================================
6. ALMACENAMIENTO DE DATOS
====================================================================

La Extensión NO almacena datos:

❌ NO utiliza chrome.storage
❌ NO crea bases de datos locales
❌ NO guarda historial de análisis
❌ NO mantiene registros de texto analizado
❌ NO almacena reportes en tu dispositivo

Resultado: No queda rastro de tu actividad al cerrar la extensión.

====================================================================
7. COMUNICACIONES EXTERNAS
====================================================================

La Extensión NO realiza comunicaciones automáticas:

❌ NO envía datos a servicios de análisis
❌ NO se conecta a APIs de terceros
❌ NO transmite información de uso
❌ NO envía telemetría o estadísticas

Única excepción: Si eliges enviar un reporte manualmente por correo.

====================================================================
8. SEGURIDAD
====================================================================

Medidas implementadas:

🔐 Content Security Policy (CSP) estricta
🛡️ Procesamiento local sin transmisión de datos
🔒 Sin almacenamiento persistente de información sensible
✅ Código fuente disponible para revisión
🚫 Sin dependencias de bibliotecas externas no verificadas
